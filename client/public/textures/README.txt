Earth texture files currently used by the homepage globe:
- earth-day.jpg
- earth-clouds.png
- earth-normal.jpg
- earth-specular.jpg
- earth-night.png

Downloaded from three.js example texture set:
- https://github.com/mrdoob/three.js/tree/dev/examples/textures/planets

Notes:
- If files are missing, the app falls back to procedural Earth/cloud textures.
- Recommended map sizes are 1024x512, 2048x1024, or 4096x2048.

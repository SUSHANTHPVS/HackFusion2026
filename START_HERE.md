# 🚀 Get Started in 3 Minutes

## ⏱️ Quick Start (For Admin Users)

### Step 1: Login (30 seconds)
```
Go to: https://your-hackathon-site.com/admin
Login with admin credentials
```

### Step 2: Find the Button (30 seconds)
```
Location: Admin Dashboard → Quick Actions section
Button: Green button with text "Send WhatsApp Link (Manual)"
```

### Step 3: Send Link (2 minutes)
```
1. Click the button
   └─ Modal opens showing all participants
   
2. Select participants
   └─ Click individual checkboxes OR "Select All"
   └─ Selection counter shows: "Selected: 5"
   
3. Choose sending method
   ├─ Option A: "Send via API"
   │  └─ For automatic instant delivery
   │  └─ Click → Messages send in 1-2 seconds
   │  └─ See: Success count + any failures
   │
   └─ Option B: "Copy & Paste Method"
      └─ For manual flexible sending
      └─ Click → Message copied to clipboard
      └─ Open personal WhatsApp
      └─ Paste in group/individual chats
      └─ Click send manually

4. See feedback
   └─ "✅ Message copied to clipboard!"
   └─ or
   └─ "✅ 3 messages sent successfully"

5. Done! ✨
   └─ Modal stays open for more sends
   └─ Can send again to different people
```

## ❓ Common Questions

### Q: Which method should I use?

**A: Use copy-paste (manual) method:**
- ✅ No setup needed
- ✅ Works immediately
- ✅ Full control
- ✅ Can customize if needed

**Use API method when:**
- ✅ Want automatic sending
- ✅ Have API configured
- ✅ Sending 100+ people
- ✅ Want scheduled timing

### Q: Can I send multiple times?

**A: YES!**
- Send to Group A
- Send to Group B  
- Send to individuals
- All at different times
- Modal stays open

### Q: What if it doesn't work?

**A: Common fixes:**
1. Make sure you're admin
2. Clear browser cache (Ctrl+Shift+Delete)
3. Refresh page (Ctrl+Shift+R)
4. Check participants exist (at least 1 approval)
5. Try copy-paste method as fallback

### Q: Can participants refuse the link?

**A: NO** - They get a link, not an invite
- They can click to join
- Or ignore if they want
- No forced invitations

### Q: Does it work on mobile?

**A: YES!**
- Button appears on mobile
- Modal is responsive
- Copy works on mobile
- Easy to use from phone

### Q: Is it free?

**A: YES!**
- Copy-paste method: FREE
- No cost at all
- Use your personal WhatsApp
- Unlimited sends

## 🆘 Still Need Help?

### Error: "Button not visible"
```
Fix:
1. Log out and log back in
2. Clear cache: Ctrl+Shift+Delete
3. Hard refresh: Ctrl+Shift+R
4. Check if you're admin user
```

### Error: "No participants shown"
```
Fix:
1. Approve at least 1 payment first
2. Refresh the modal
3. Participants should appear
```

### Error: "Copy didn't work"
```
Fix:
1. See message in modal
2. Manually copy it
3. Try different browser
4. Use desktop instead of mobile
```

### Still stuck?
```
Ask for help:
1. Check browser console (F12)
2. Note the error message
3. Contact developer with:
   - What you tried
   - What error appeared
   - Screenshot if possible
```
